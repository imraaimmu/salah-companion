# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In addition, because this is a project serving people at prayer:

- Discuss differences between madhhabs and scholarly opinions with respect and adab.
  No one is mocked for how they pray.
- Keep discussion about the app. Sectarian arguments, takfir and personal attacks are
  not tolerated.
- Never share another person's prayer recordings, even landmark-only files, outside the
  project's test set or without their consent.

## Reporting

Report unacceptable behaviour privately to the maintainers using GitHub's
"Report content" feature or a private security advisory on this repository. Reports are
handled confidentially.
