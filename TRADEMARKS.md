# Name and Logo Policy

"Salah Companion" and the project logo identify this project and its official free
releases. The licence lets you fork the code; it does not let you use the name or logo.

- **Forks must use a different name and icon**, so no one confuses an unofficial copy,
  possibly with ads or data collection, with the free, private official app.
- You may say your fork is "based on Salah Companion" in its description.
- You may use the name to talk about the project, write tutorials, or link to it.
- Store listings using the name or logo are allowed only for official releases
  published by the maintainers.

Questions: open an issue with the `legal` label.
