# Recitation audio

No audio files are committed yet.

The plan (see `docs/SPEC.md`, section "Audio and recitation content") is to commission a
qualified qari to record Al-Fatiha and the pilot surahs, one file per ayah, in a slow
follow-along style. The recording's licence will be added here before any audio is
committed. It will allow free use inside this app and its free, noncommercial forks, and
forbid any commercial use, the same as the code.

Until then, developers use placeholder tones generated by a script, so no third-party
recordings enter the repository without written permission.

Every audio file must be signed off by a qualified qari before release.
