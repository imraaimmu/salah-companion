# Recitation audio

No recitation audio is committed yet; only the placeholder tones described below.

The plan (see `docs/SPEC.md`, section "Audio and recitation content") is to commission a
qualified qari to record Al-Fatiha and the pilot surahs, one file per ayah, in a slow
follow-along style. The recording's licence will be added here before any audio is
committed. It will allow free use inside this app and its free, noncommercial forks, and
forbid any commercial use, the same as the code.

Until then, developers use placeholder tones generated by a script, so no third-party
recordings enter the repository without written permission.

## Placeholder tones (development only)

`scripts/make_placeholder_audio.py` (Python 3 standard library only, no network, no
ffmpeg) writes one sine-tone clip per ayah to `app/assets/audio/placeholder/`
(`SSSAAA.wav`, 16 kHz mono 16-bit PCM, about 3.7 MB for all 93 ayahs) and a
`catalog.json` that maps surah:ayah to the asset path and its duration in milliseconds.
Each surah has its own pitch, each ayah is 1.0-1.5 s with a short higher blip at the end.
The catalog says `"placeholder": true`. They are not recitation and must never ship in a
release.

The output is deterministic. Only `catalog.json` is committed; the audio files are
generated (binary files are kept out of git). Run the script once after cloning, before
`flutter test` or `flutter run`. The Android build (`makePlaceholderAudio` Gradle task)
runs it with `--if-missing` before the assets are bundled, and
`app/test/content_assets_test.dart` runs it too if the files are missing.

The script also writes `app/assets/audio/silence_10s.wav` (silent, 8 kHz mono, also not
committed), which
the player clips to make the opening-dua pause and the gaps between ayahs. It is part of
the app, not a placeholder.

The real recordings (#18) replace the placeholder folder and catalog, using the same
catalog format. The generated files are original works of this project and fall under
LICENSE.

Every audio file must be signed off by a qualified qari before release.
